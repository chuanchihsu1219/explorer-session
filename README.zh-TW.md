# 檔案總管保存（Explorer Session）

[English](README.md) | **繁體中文**

檔案總管當掉、不正常關機或誤關之後，把視窗和分頁照原樣找回來。

## 為什麼做這個

**同時推好幾個專案時，開著的資料夾就是你的待辦清單，而 Windows 隨時可能不打招呼就把這份清單丟掉。**

想像一個普通的下午：一個視窗開著客戶簡報，一個視窗是資料 pipeline，底下五個子資料夾分頁，最後面還有一個從星期二就沒碰過的 side project。然後檔案總管當掉了。以作者的例子來說，它連續跑了兩週，繪圖資源一點一點洩漏，最後撐不住。工作列閃一下，所有資料夾視窗全部消失。

- **緊急的工作會回來**：你記得它，會自己把資料夾翻出來。
- **side project 不會回來**：那個開著的視窗，是它還存在的唯一提醒。眼不見，就忘了。

Windows 內建的「登入時還原先前的資料夾視窗」只在正常重開機或登出後才有作用。當掉、斷電、記憶體耗盡，或手滑按到 ✕，全部都救不回來。

**檔案總管保存補上的就是這個缺口：**

| 發生什麼事 | 只靠 Windows | 加上檔案總管保存 |
|---|---|---|
| 正常重開機、關機、登出 | ✅ 會還原 | ✅ 會還原（交給 Windows，本工具不介入） |
| 檔案總管當掉或重開 | ❌ 全部消失 | ✅ 幾秒內自動還原 |
| 不正常關機（記憶體耗盡、斷電） | ❌ 全部消失 | ✅ 登入後自動還原 |
| 手滑關掉視窗或分頁 | ❌ 消失 | ✅ 點一下系統匣圖示，像瀏覽器的 Ctrl+Shift+T |
| 「我昨天早上開了哪些資料夾？」 | ❌ 無從得知 | ✅ 從歷史選單挑一個時間點 |

## 開始使用

**編譯一次、啟動一次，之後每次登入它都會自己在背景執行。**

**系統需求**：Windows 11、有分頁的檔案總管（在 25H2 上開發）。不用另外安裝任何東西，用 Windows 內建的 .NET Framework 編譯器就能編譯。

```powershell
git clone https://github.com/chuanchihsu1219/explorer-session.git
cd explorer-session
powershell -ExecutionPolicy Bypass -File .\build.ps1
explorer.exe "$PWD\bin\ExplorerSession.exe"
```

- 系統匣會出現一個檔案總管圖示。它可能被收在隱藏區（`^`），想常駐顯示就把它拖到工作列上。
- 第一次啟動會自動開啟「**登入時自動啟動**」，並在開始功能表放一個「**還原檔案總管**」捷徑。
- 這樣就完成了，沒有任何需要設定的東西。

## 使用方式

**你不需要改變任何操作習慣：系統匣圖示是唯一的入口，它在系統匣裡，就代表正在記錄。**

### 各種情況下你會遇到什麼

| 情況 | 你會看到 | 你要做的 |
|---|---|---|
| 檔案總管當掉或重開 | 工作列閃一下。幾秒後原本的視窗一個個開回來，分頁、位置、選中的分頁都跟原本一樣，右下角會跳通知 | 不用做。就算先按了工作列圖示也沒關係，只是多一個首頁視窗 |
| 正常重開機、關機、登出 | 交給 Windows 內建的還原，本工具不介入 | 不用做 |
| 不正常關機（記憶體耗盡、斷電、強制關機） | 登入後大約半分鐘，視窗自動回來 | 不用做 |
| 誤關一個視窗或分頁 | — | **左鍵點系統匣圖示**。每按一次往前找回一個，跟 Chrome 的 Ctrl+Shift+T 一樣 |
| 想回到某個時間點的視窗組合 | — | 右鍵 →「從歷史還原」→ 挑一筆 |

- **已經開著的資料夾一律跳過**，不會重複開。

### 右鍵選單

| 項目 | 作用 |
|---|---|
| 上次快照 HH:mm:ss · N 窗 M 頁 | 狀態列；時間有在更新，就代表正在記錄 |
| 找回最近關閉的（同左鍵） | 同左鍵 |
| 最近關閉 ▸ | 最近 20 筆關閉的視窗或分頁，可以直接挑一個 |
| 從歷史還原 ▸ | 歷史紀錄，⚠ 標記的是「當掉前」或「不正常關機前」 |
| 暫停記錄 | 暫時不記錄，例如要整理大量視窗時 |
| 登入時自動啟動 | **預設開啟**。開機登入後自動在背景執行，並保留開始功能表的「還原檔案總管」捷徑；取消勾選後就不再自動啟動 |
| 開啟資料夾 | 打開執行期資料夾，可以看 `log.txt` |
| 結束 | 關掉程式，會記為正常結束 |

### 程式被關掉了怎麼打開

**按開始鍵，搜尋「還原檔案總管」，點一下就會重新打開。**

**怎麼知道它被關掉了**
- 系統匣裡的圖示不見了。圖示有可能被收在隱藏區，記得也點 `^` 展開看看。
- 右鍵選單裡「上次快照」的時間停住不動。

**重新打開的方法**

| 方法 | 什麼時候用 |
|---|---|
| **開始功能表搜尋「還原檔案總管」** | 平常最快的方法 |
| 重新開機 | 「登入時自動啟動」有勾，登入後它會自己起來 |
| 直接執行 `bin\ExplorerSession.exe` | 萬一捷徑被刪掉時的備援 |

- **同一個捷徑，程式在跑和不在跑時的作用不同**：
  - 程式沒在跑：點了就是啟動它，不會順便執行還原。
  - 程式已經在跑：點了等於按系統匣圖示左鍵，會找回最近關閉的視窗或分頁。
  - 所以不用擔心點了會開出兩份程式，它永遠只會有一份在跑。

**關掉期間的影響**
- **已經存下的紀錄都還在**：歷史紀錄和「最近關閉」存在硬碟裡，重新打開後照樣能用。
- **關掉期間不會記錄**：這段時間裡檔案總管若當掉，不會自動還原。不過重新打開後，可以從「從歷史還原」挑關掉前的那一份。

## 運作原理

**每 15 秒讀一次。切換資料夾只更新目前狀態，只有視窗或分頁的組成變了、而且穩定 2 分鐘，才寫進歷史紀錄。**

| 層 | 檔案 | 記什麼 | 用在哪 |
|---|---|---|---|
| 目前狀態 | `live.json` | 每個分頁**現在**所在的資料夾、位置、選中的分頁 | 當掉、不正常關機後的自動還原 |
| 最近關閉 | `closed.json` | 最近 20 筆真正被關掉的視窗或分頁 | 左鍵、「最近關閉」 |
| 歷史紀錄 | `history\*.json` | 組成穩定的時間點，加上當掉前、關機前的檢查點 | 「從歷史還原」 |

- **分頁靠「分頁本身」辨認，不靠路徑**：每個分頁有一個專屬的內部視窗代號，切換資料夾不會改變。所以在子資料夾之間切來切去，不會被當成「關閉分頁」，也不會洗掉歷史紀錄。
- **歷史紀錄的保留規則**：

| 距今 | 保留 |
|---|---|
| 1 小時內 | 全部 |
| 1–24 小時 | 每 15 分鐘留最後一份 |
| 1–7 天 | 每天留最後一份 |
| ⚠ 當掉前、不正常關機前、關機前 | 30 天 |

- **當掉後只會還原「當掉前」那一份**：每份快照都記錄它屬於哪一次檔案總管執行。當掉後新開的視窗屬於新的一次執行，不會被拿去還原。
- **偵測檔案總管重開，靠的是它重開時廣播的 `TaskbarCreated` 訊息**：常駐程式本來就要靠這個訊息把圖示掛回去，所以不必另外監看事件記錄。

## 已知限制

- **開啟不到 15 秒就關掉的視窗**：還沒被記到，所以找不回來。
- **搜尋結果分頁**：記到的只是顯示名稱，不是路徑，所以會跳過。
- **「新增分頁」用的是 Windows 沒有公開文件的指令**：哪天 Windows 更新讓它失效，其餘分頁會改成各開一個視窗，`log.txt` 會寫 `new-tab failed`。
- **同一個視窗裡有兩個同名分頁時**：選中的分頁、分頁順序可能對調。

## 開發

| 要做 | 指令（在本資料夾的 PowerShell） |
|---|---|
| 改程式後重新編譯 | 先 `bin\ExplorerSession.exe --quit`，再 `.\build.ps1` |
| 印一次快照 | `bin\ExplorerSession.exe --snapshot-once out.json` |
| 用指定檔案還原 | `bin\ExplorerSession.exe --restore some.json` |
| 模擬檔案總管重開／不正常關機後登入 | `--simulate-shell-restart`／`--simulate-unclean-logon`（交給常駐程式執行） |

- **原始碼**在 `src\`（C#、.NET Framework 4.x，不用 NuGet 套件）。
- **介面語言自動切換**：Windows 顯示語言是繁體中文（zh-TW、zh-HK、zh-MO）就顯示中文，其他語言顯示英文。要強制指定，可以設環境變數 `EXPLORER_SESSION_LANG=zh` 或 `en`。
- **執行期資料**在 `%LOCALAPPDATA%\ExplorerSession\`。刻意不放 OneDrive 這類同步資料夾，因為每 15 秒寫一次，會一直觸發同步。
- **要用 `explorer.exe` 啟動**：
  - 從 Claude Desktop 這類封裝成 MSIX 的 app 的終端機直接執行，程式會掛在該 app 底下，app 一重啟就被一起收掉。
  - 它寫的 `AppData` 也會被導到該 app 的私有副本。
- **登入時自動啟動**寫的是 `HKCU\...\Run\ExplorerSession`。不用排程工作，也不需要管理員權限。
